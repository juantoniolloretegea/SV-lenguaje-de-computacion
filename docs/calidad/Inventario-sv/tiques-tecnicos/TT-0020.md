# TT-0020 · CubeCL y rust-gpu: realización de cálculo Rust para AMD

**Suceso:** [S39](../sucesos/SUCESOS_SV.md#s39), revisión 39.  
**Estado:** pendiente. **Alta y actualización:** 2026-10-05T18:29:13Z.  
El estado pendiente corresponde a la realización y recepción técnica; la evaluación documental de base está concluida.

## Objeto y evidencia

Se incorpora CubeCL como componente de cálculo en evaluación para AMD Instinct MI300X/gfx942, con rust-gpu como alternativa. Evaluación documental concluida; CubeCL prioritario provisional, rust-gpu alternativa. MFMA/CDNA por LLVM en MI300X, exactitud independiente y dependencias pendientes de prueba. Sin instalación, inferencia ni recepción GPU. Kimi K3 y GLM-5.3/Flash permanecen como candidatos en estudio de viabilidad, sin ensayo ni descarte definitivo.

## Dependencia y retorno

Antes de una intervención material deben fijarse versiones, casos, tolerancias, cotas y dependencias admisibles. La prueba propuesta es una única operación representativa; detectar una GPU o sumar un vector no acredita esa capacidad. rust-gpu requiere comprobar antes controlador y extensiones Vulkan efectivas. Si el trabajo exige un compilador o arquitectura de modelo completos, se registra el impedimento antes de ampliar el alcance.

No se inicia desarrollo o ejecución por esta alta documental; no se contratan recursos ni se transfieren resultados entre modelos. Una recepción favorable de la operación tampoco habilita inferencia completa ni examen. El Núcleo, semántica V0.2 e IR 0.3 se mantienen intactos. Los expedientes Qwen, Safeguard y MCP conservan sus condiciones y recepciones independientes.
