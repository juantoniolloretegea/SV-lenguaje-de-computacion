La fuente es exclusivamente la caché profesional española del PDQ del NCI sobre leucemia de células pilosas, actualizada el 14/11/2024 y recuperada el 26/09/2026. Se fijan revisión de custodia, huellas de catálogo, HTML y secciones en el protocolo y en la clave.

El vector ordenado P01–P25 utiliza 0 para correcto, 1 para erróneo y U para indeterminación auténtica. Los fallos técnicos y las posiciones pendientes no se rellenan con U. Se aplica el umbral doctrinal T(n)=⌊7n/9⌋, que da 19 para 25 posiciones, y se separa la condición adicional de admisión: veinte críticas en 0. Un 1 crítico impide admitir el ensayo; un U crítico mantiene indeterminación. El polígono conserva orden y radios 1, 2 y 3 para 0, 1 y U.

El cálculo auxiliar Rust recibe adjudicaciones revisadas; no decide medicina ni constituye una implementación soberana del núcleo. El resultado favorable sólo vale para el instrumento y la configuración efectivamente examinados, no para aptitud clínica, conocimiento global ni admisión de conocimiento del dominio.
