Scope. This page provides diagnostic access from the published implementation and does not redefine the canonical catalog.

1. Applicable catalog

For Grammar 0.2 and IR 0.3, the effective catalog contains 50 codes. Version 0.3 retains the 0.2 catalog and adds E110, E305 and E308.

2. v0.3 additions

3. Layer separation

E... codes belong to the compiler. Messages about WebAssembly loading, source size, UTF-8, digests or transport belong to the interface and are not semantic Language diagnostics.

4. Preserved historical divergence

The catalog preserves the historical E204 divergence: historical IR names it MissingConflictOperator, while the effective early-compilation catalog uses QueryMissingContext. The published implementation neither hides nor locally reassigns this divergence.

5. Evidentiary limit

Regression confirms acceptance/rejection over the current corpus, but does not establish exact diagnostic-text identity between Python and Rust/WebAssembly.
