# Historial público de versiones Beta del Lenguaje SV

Este directorio conserva la procedencia pública de las versiones Beta del Lenguaje SV y el trabajo experimental que quedó pendiente en cada una de ellas.

El historial Beta es independiente del historial de versiones estables integrado en `docs/calidad/HISTORIAL_VERSIONES_LENGUAJE_SV.md`. Una capacidad descrita como propuesta o pendiente en una Beta no adquiere por ello el estatuto de requisito, deuda o compromiso de una versión estable.

La incorporación de una capacidad procedente de Beta a una versión estable requiere integración expresa en el repositorio soberano, comprobaciones aplicables y registro de Calidad.
