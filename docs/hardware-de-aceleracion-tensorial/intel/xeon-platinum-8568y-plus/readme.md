# Intel Xeon Platinum 8568Y+

**CPU anfitriona del ensayo AMD Instinct MI300X VF · 16 de octubre de 2026.**

El Explorador Tensorial del SV identificó `INTEL(R) XEON(R) PLATINUM 8568Y+` en una máquina virtual de AMD Developer Cloud, región ATL1, con 20 procesadores lógicos disponibles y 253.347.037.184 bytes de RAM observada. El proveedor de la plataforma no determina el fabricante de su CPU.

El procesador efectuó el control anfitrión y 82 productos matriciales CPU exactos en dos ejecuciones. El Selector del Árbitro - Director CPU/GPU/TPU/NPU eligió CPU en cinco de los seis casos de selección automática. La realización medida no acredita utilización simultánea de todos los procesadores lógicos.

El [informe MI300X VF](../../amd/instinct-mi300x-vf/readme.md) conserva el método, las mediciones CPU y GPU, el diagnóstico de recuperación, las fuentes y todos los registros. Ambas fichas describen los mismos dos recorridos experimentales; sus cifras no deben sumarse.
